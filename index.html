Learn Go From Kubernetes

You already know Pods, labels, controllers and manifests. This course teaches Go by having you rebuild those pieces, from a Pod struct up to a working operator.

  1. LearnRead the lesson's tutorial and answer its self-checks.
  2. PracticeClone the repo and fill in the TODOs until go test passes.
  3. ReviewTake the mistakes quiz to catch the subtle parts.

Lessons

  • 01

    Basics: modelling a Pod

    Structs, slices, maps, methods, pointer receivers, and table-driven tests. You build label selectors and the READY column of kubectl get pods.

    Tutorial Exercises Mistakes quiz

  • 02

    Interfaces & errors: a toy API server

    Implicit interfaces, embedding, type switches, error wrapping, errors.Is/As. You build runtime.Object, IsNotFound, and an in-memory store.

    Tutorial Exercises Mistakes quiz

  • 03

    Encoding: parsing a Deployment manifest

    Struct tags, encoding/json, sigs.k8s.io/yaml, pointer fields, a first look at generics, and errors.Join.

    Tutorial Exercises

  • 04 · coming soon

    Concurrency: a work queue and reconcile loop

    Goroutines, channels, select, sync, context.

  • 05 · coming soon

    HTTP services: probes and graceful shutdown

    net/http, /healthz and /readyz, SIGTERM handling, running in kind.

  • 06 · coming soon

    client-go

    List and watch Pods against a real cluster.

  • 07 · coming soon

    Informers & controllers

    A controller that labels and annotates Pods.

  • 08 · coming soon

    Operators

    A CRD and operator with controller-runtime.
